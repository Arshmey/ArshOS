ArshOS is a regular pet project that develops in the author's free time. Perhaps in the future it will become not just a simple operating system, but something more.

# Windows

How to compile and run
1. Made folder "test"
2. Run compile.bat
3. Run unite.bat

# Linux

1. Run Comp.sh
2. Run Unite.sh
3. Run Start.sh

PS You have problem? See below
1. If dont't run, you haven't qemu. Download in official site.
2. If don't compile. Download in official site NASM and setup path in Windows Enviroment.
